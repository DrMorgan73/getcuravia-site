# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to **info@iecincglobal.com**.
Include a description of the issue, steps to reproduce, and the affected
version or commit where possible. We will acknowledge receipt and work with
you on a fix and disclosure timeline.

Please do not open public GitHub issues for unpatched vulnerabilities.

## Scope

This repository hosts the public marketing website for CURAVIA
(www.getcuravia.com), currently in pilot stage. It contains no patient data,
no credentials, and no backend services.
